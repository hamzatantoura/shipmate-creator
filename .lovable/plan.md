## المشكلة
دالة التحقق في `CourierPricingTiers.tsx` تعتبر الحدود المتلامسة (مثل شريحة `0-5` ثم `5-10`) تداخلاً، فترفض حفظ أي شريحة جديدة لأن زر «إضافة شريحة» يُولّدها بـ `min = max السابق`.

## الإصلاح
في `src/components/admin/CourierPricingTiers.tsx` داخل دالة `validate()`:

1. تعديل شرط التداخل ليعامل النطاقات كـ نصف-مفتوحة `[min, max)`، فيسمح بالتلامس على الحدود:
   ```ts
   const overlap = Math.max(a.min, b.min) < Math.min(a.max, b.max);
   ```
2. تحسين نص رسالة الخطأ ليُظهر القيم بالأرقام:
   `"تتداخل الشريحة [5–15] مع الشريحة [0–10]"` بدل أرقام الصفوف فقط.
